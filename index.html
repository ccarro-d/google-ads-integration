Google Ads Reporting Tool

Read-only reporting client · César Carro, independent paid media specialist

Private, internal tool operated by César Carro, an independent paid media specialist, to read and analyze Google Ads performance data for the accounts under his manager account (MCC 295-651-2723), including his own and those of a small number of direct clients he manages. Data is used exclusively to produce reports for those same account owners and is never redistributed to third parties.

What this tool does

It is a single-operator, read-only tool. It has no public interface and no external users: only the operator runs it, locally, on his own machine. It retrieves campaign performance data for reporting and analysis, and it does not create, edit, or delete any advertising entity.

How it uses the Google Ads API

The tool performs read operations only:

  • Running GAQL search queries to read reporting data
  • Listing accessible customer accounts
  • Retrieving resource metadata

It requests a single OAuth scope, https://www.googleapis.com/auth/adwords, and no other. No write operations are performed, and no data is shared with or transferred to any third party.

How it is built

The tool is built on Google's official Google Ads MCP server (googleads/google-ads-mcp) and runs locally as a command-line process. There is no hosted backend and no intermediary server. It is associated with Google Cloud project number 531937630254 and operates under manager account (MCC) 295-651-2723.
