Privacy Policy

Last updated: 11 August 2026

This tool is operated by César Carro, an independent paid media specialist. It is a private, single-operator, read-only tool with no public interface and no external users.

Data we access

Through the Google Ads API, the tool reads advertising and reporting data from the Google Ads accounts under the operator's manager account (MCC 295-651-2723) — his own accounts and those of a small number of direct clients he manages and is authorized to access. Access is strictly read-only; the tool never creates, modifies, or deletes any advertising entity. It requests a single OAuth scope, https://www.googleapis.com/auth/adwords.

How data is used

Data is used exclusively to generate reports and analysis for the owners of the accounts under management. It is never sold, redistributed, or transferred to any third party.

Data retention

The tool does not maintain any persistent or public database. Data is fetched on demand, processed locally on the operator's machine, and any cache is local and ephemeral. Nothing is replicated to external services, and there is no cloud backup.

Limited Use

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

OAuth and credential security

Authentication uses Google OAuth 2.0. Credentials are stored in a local file on the operator's machine with restricted permissions, are never committed to version control, and are never sent to any intermediary or third-party server. Access can be revoked at any time from the Google account's security settings.

Contact

For any question about this policy, contact César Carro at c.carro.diaz@gmail.com.
